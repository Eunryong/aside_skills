# Aside Skills

Custom user skills for Aside AI agent/browser.

## Included Skills

- **youtube-summarizer**: Summarize YouTube videos by fetching transcript and metadata.
- **ponytail**: Minimalist coding & refactoring guidelines.
- **ponytail-review**: Code review focused on removing over-engineering.
- **i-have-adhd**: Action-first, numbered, concise, stateful response guidance.
